# גרסה 1.0.1

## תיקונים
- קיבוע .NET SDK לענף 9.0 כדי למנוע בחירה אוטומטית ב־SDK 10, שגרמה לכשל בטעינת משימת MSBuild של WinUI.
- הוסרה הגדרה כפולה של `Grid.ColumnDefinitions` במסך הראשי.
- נשמרו תשתית המתקין ל־Windows ותהליך האריזה האוטומטי.

## מצב בדיקות
- תיקוני המקור וקיבוע ה־SDK הועלו למאגר.
- בניית Windows ויצירת קובץ EXE ייחשבו מאומתות רק לאחר ש־GitHub Actions יסיים בהצלחה.
