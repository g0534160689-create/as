# גרסה 1.0.45 – חבילת יכולות ניהול ושליטה חזותית

## יכולות שנוספו
- WebView2 פנימי עם אכיפת רשימה שחורה, רשימה לבנה ומדיניות קישורים חיצוניים.
- טיפול בחלונות קופצים לפי ההרשאות שהוגדרו בניהול.
- מצב בחירת אלמנט בדף, שמירת בוררי CSS והסתרה מתמשכת לאחר טעינת דף.
- שחזור הסתרות בלי להסיר מאפייני display מקוריים של האתר.
- שירות שמירת הגדרות עם גיבוי ושחזור אוטומטי מקובץ הגיבוי במקרה של JSON פגום.
- יומן פעילות עם חיפוש, רענון וניקוי.
- שמירת ערכת נושא כהה/בהירה והחלתה בהפעלה הבאה.
- תיעוד פעולות ומגבלות שימוש ב־README.

## מגבלות ידועות
- קורא הכרטיסים הפיזי אינו מחובר עדיין.
- יש לבדוק את זרימות ההתחברות וההרשאות של אתר רב־קו במחשב Windows אמיתי.
- בוררי CSS עלולים להשתנות אם האתר משנה את מבנה הדף.
