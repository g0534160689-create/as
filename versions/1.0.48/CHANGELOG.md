# גרסה 1.0.48 – מערכת ניהול, דפדפן ושליטה חזותית

## מה כלול
- WebView2 פנימי.
- מדיניות ניווט לפי רשימה שחורה, רשימה לבנה ומצב רשימה לבנה בלבד.
- טיפול בחלונות קופצים בהתאם להגדרות.
- בחירה חזותית של אלמנטים בדף, שמירת בוררי CSS והסתרה לאחר טעינה.
- שחזור הסתרות תוך שמירה על ערכי display המקוריים של האתר.
- שמירת הגדרות JSON עם קובץ גיבוי וניסיון שחזור אוטומטי.
- יומן פעילות מקומי עם חיפוש, רענון וניקוי.
- ערכת נושא כהה/בהירה הנשמרת להפעלה הבאה.
- מסך ראשי מעודכן והוראות שימוש ומגבלות ב־README.
